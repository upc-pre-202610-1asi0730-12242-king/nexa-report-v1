# Annex A: Annexes Index

Los anexos del reporte Nexa se organizan en archivos Markdown independientes para facilitar el mantenimiento Docs-as-Code y conservar la trazabilidad entre evidencias históricas de AV1, TB1 y AV2, junto con las evidencias académicas, técnicas y documentales TB2 actualmente disponibles.

Esta organización distingue los registros verificables de cada entrega e incorpora las Validation Interviews TB2 y la evidencia GitHub disponible del Project Report. Las nuevas versiones audiovisuales y la evidencia de un release documental formal se incorporarán solo si son publicadas posteriormente por el equipo.

| Anexo | Archivo | Contenido |
|---|---|---|
| Annex A: Annexes Index | `report/annexes/annex-a-annexes.md` | Índice general de anexos y criterio de organización del reporte. |
| Annex B: Video Evidence | `report/annexes/annex-b-video-evidence.md` | Evidencias audiovisuales históricas e integración multimedia verificada en la Landing Page durante TB2. |
| Annex C: Validation Evidence | `report/annexes/annex-c-validation-evidence.md` | Needfinding, Validation Interviews AV2/TB2, evaluación heurística, hallazgos de validación y relación con el Lean UX Process. |
| Annex D: GitHub Repository Evidence | `report/annexes/annex-d-github-repository-evidence.md` | Repositorios, releases históricos AV2, releases finales TB2 de producto, evidencia GitHub del Project Report, commits, branches, GitHub Insights/Pulse y tag documental TB2. |
| Annex E: Deployment and Services Evidence | `report/annexes/annex-e-deployment-and-services-evidence.md` | Jira, Render, Swagger/OpenAPI, servicios externos, i18n, accesibilidad e integración multimedia. |
| Annex F: AV2 Controlled Evidence | `report/annexes/annex-f-av2-controlled-evidence.md` | Evidencia controlada AV2 histórica y límites declarados del corte AV2. |

> *Nota*: Los anexos reúnen evidencia histórica, académica, técnica y documental disponible sin anticipar videos finales TB2 ni un release documental formal que todavía no cuente con evidencia específica. Elaboración propia.
