# Release Notes

This folder documents the SemVer release notes for the `nexa-ecosystem-report` repository.

## Policy

- One Markdown file is maintained per version listed in `report/front-matter/02-version-history.md`.
- Major releases summarize a full academic delivery state.
- Minor releases describe only the incremental documentation scope of that version.
- Patch releases describe corrections, synchronization, cleanup, or publication polish.
- Product deployment evidence remains linked to Website, WebApp, and Platform releases.
